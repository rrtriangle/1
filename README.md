# 야간 근무 (가제) — 데모 v0.5 (8주)

회색 박스 데모입니다. 8주(56일) 동안 공장장 자리를 지키는 것이 목표예요.
v0.4는 **공간(구역·칸·전력), 법(근로시간·중대사고), 감사 3종**이 한 판 안에서 같이 도는지 확인합니다.

## 여는 법
1. [Godot 4.2 이상](https://godotengine.org/download) 표준판(Standard, .NET 아님)을 설치합니다.
2. Godot 프로젝트 관리자에서 **가져오기** → 이 폴더의 `project.godot` 선택.
3. F5로 실행. 한글은 PC에 설치된 글꼴(맑은 고딕 등)을 씁니다.

## 흐름
교대 회의(탭 4개) → 근무(리얼타임) → 보고서 → (7일마다) 주간 결산. 주간·야간 2교대.

## 공간
- **구역 9개**: 사무동·생산동·출하장·정문·물류 창고 A는 개방, 물류 창고 B·정제동·2번 반응기동은 폐쇄(탈환 가능), 연구동은 이번 데모에서 잠김
- **칸**: 구역마다 대/중/소 빈 방 자리. 회의의 "시설·전력" 탭에서 방을 짓는다
  - 휴게실 150(중), 정제실 400(중), 반응실 800(대, 생산동·2번 반응기동), 물류 창고 300(대), 흡연실 60(소, 줄담배 직원용)
  - 첫 결정: 휴게실을 생산동에 지으면 가깝지만 시끄럽고(휴식 75%) 반응실 사고가 번진다. 사무동은 조용하지만 복도를 걸어가야 한다
- **복도**: 근무 중 다른 구역으로 보내면 1시간 걸어간다. 밤에 혼자, 어두운 복도면 '그것'과 마주칠 수 있다
- **전력 한도**: 처음 7. 대 칸 조명 2, 그 밖의 방·복도 1, CCTV 1. 다 켤 수 없다. 정전이 오면 그 교대 동안 −2
- **설치물**: CCTV 150(불이 꺼져도 인원수 표시, 명단과 안 맞으면 경고), 비상 조명 40(정전에도 유지)
- **탈환**: 본사 조건(일차·신뢰도)과 비용 → 2명 이상이 정화 작업 N교대 → 빈 칸, 정원 +1, 전력 +2
  - 물류 창고 B: 8일차 이후, 신뢰도 40, 800, 3교대 / 정제동: 신뢰도 50, 1500, 5교대 / 2번 반응기동: 43일차 이후, 2500, 6교대

## 생산
반응실 → 정제실 → 물류 창고가 한 줄. 창고 직원이 없으면 정제실 출구(3드럼)에서 막힌다.
트럭은 낮 10시·16시에 12드럼씩 싣고 간다(물류 창고가 둘이면 13시 추가). 돈은 출하할 때 들어온다.

## 법
- **근로시간 장부**: 주 4교대 기본, 5교대째는 연장수당, 6교대째부터 위반. 교대 사이에는 한 교대를 쉬어야 한다. 야간 근무자는 수당 1.5배
  - 위반은 장부에 남아 감사 때 지적. 특별연장 인가(그 주 한도 +1)는 본사 신뢰도 −5
  - 회의의 기본 배치는 법을 어기지 않게 골라 준다. 사람이 모자라면 빈 교대가 생긴다
- **중대사고**(실종, 부상 2명): 보고하면 조사. 위험성평가(QC실에 한 교대 배치), 근로시간 준수, 작업중지 요구 수용 기록이 있으면 면책. 없으면 특별감사로 직행
- **작업중지권**: 안전 제일 직원이 반응실에 있으면 역압 때 "세우자"고 요구한다. 받아들이면 사고 없이 그 교대 정지

## 감사
- **적자 감사**: 주간 결산 적자 → 다음 주 1주 상주
- **정기감사**: 4주차·8주차. 2주 전에 감사관 유형과 함께 예고. 숨긴 사고와 근로시간 장부를 전부 본다. 통과하면 신뢰도 +10, 정원 +1
- 감사관 4종(서류파·현장파·숫자파·형식파)은 보는 것과 숨긴 사고를 찾는 확률이 다르다. 지적 2건 이하면 통과
- 불통과 → 2주 뒤 **특별감사**(지적 1건 이하). 적자 때문에 온 경우만 2주 연속 흑자로 취소된다. 불통과면 공장장 교체
- 감사 직후 한 주는 새 감사가 오지 않는다. 정기감사 직전의 적자는 정기감사에 합쳐진다
- **본사 신뢰도**(시작 50): 흑자 +2, 적자 −4, 감사 통과·불통과로 오르내린다. 0이면 해임
- 「심부름」을 다녀온 직원은 출근 기록이 두 번씩 찍힌다. 서류파·숫자파 감사 주간에 3교대 넘게 쓰면 지적

## 작은 쾌감
역압 때 선택지마다 성공 확률이 보인다. 직접 지시가 성공하면 20%로 **★ 완벽한 차단**(그 교대 역압 면역, 관찰 기록 +2).

## v0.3에서 달라진 것
- 4주 → 8주, 방 4개 고정 → 구역·칸·건설·탈환, 조명 무료 → 전력 한도
- 근로시간 장부로 "한 사람을 하루 두 교대 돌리기"가 위반이 됐다
- 출하: 창고 직원이 입고, 트럭이 낮에 싣고 간다
- 정기감사, 본사 신뢰도, 중대사고 조사, 작업중지권, 역압 확률 표시와 완벽한 차단
- 폭주의 밤은 넣지 않았다 (기획서에서도 보류)

## 아직 없는 것
근무 수칙·연구, 흑색 침전물과 혼입, 주문·고객사, 셔터·출입 통제, 도면과 실제가 달라지는 공간, 연구동, 저장

## 수치 바꾸는 곳
`scripts/game.gd` 맨 위 상수 (경제, 근로시간, 전력, 구역·칸·방 정의, 감사관). 시간 속도는 `scripts/main.gd`의 `HOUR_SEC`.

## 자동 테스트 (`_sim/`)
- `godot --headless --script res://_sim/sim4.gd -- runs=1000` : 성향 7종, 8주 결과 (`policy=careful`, `audit=1`, `rest=office`, `nohire=1`, `rate=100`)
- `godot --headless --script res://_sim/ui_autopilot.gd -- seed=1 wild=1` : 실제 화면에서 버튼·맵을 무작위로 눌러 끝까지 진행

## v0.5: 이상현상 공통 틀
- **오염 5단계**: 25마다 한 단계. 캐릭터 그림에 표시가 얹힌다
  | 오염 | 겉모습 | 효과 |
  | --- | --- | --- |
  | 25~ | 다크서클 | 피로 회복 70% |
  | 50~ | 초점 없는 눈 | 같은 방 동료 스트레스 |
  | 75~ | 검은 무늬 | 그 방에 '한 명 더'가 잘 생긴다 |
  | 100 | 변이 | 같은 방이면 둘이어도 '한 명 더'가 끼어들고, 동료가 물든다 |
- 회의 "인사·근로시간" 탭: 휴직 3일(오염 50 이상, 쉬는 동안 교대마다 −8), 정밀 검진·정화 300(−40)
- 「심부름」 직원: 밤 근무마다 오염 +4. 일은 잘하지만 쓸수록 변해 간다
- 확장: 물류 창고 B에 2호 반응실을 지을 수 있다. 2번 반응기동은 29일차부터. 반응실이 둘이면 13시 트럭 추가
- 주간 결산은 **영업 손익**으로 본다. 건설·탈환·설치 투자비는 빼서, 투자한 주가 적자로 잡혀 감사가 오지 않는다
