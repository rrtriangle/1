# 야간 근무 (가제) — 데모 v0.6

화학 공장의 공장장이 되어, 낮에는 공장을 굴려 돈을 벌고 밤에는 버티는 관리 시뮬레이션 + 공포.
v0.6은 v0.5를 플레이해 보고 기획서 20장 "재설계"에 따라 **새로 짠** 버전입니다.

## 여는 법
1. [Godot 4.2 이상](https://godotengine.org/download) 표준판(Standard, .NET 아님)을 받습니다.
2. 프로젝트 관리자에서 **가져오기** → 이 폴더의 `project.godot`.
3. F5로 실행. 한글은 PC에 설치된 글꼴(맑은 고딕 등)을 씁니다.

## 데모 범위
프롤로그 3일 + 1주차 (10일차 밤까지). 프롤로그 동안은 반장들이 무전으로 안내합니다.

## 하는 일
- **교대 회의** (08:00, 20:00): 지난 교대 보고서를 보고, 이번 조의 배치·가동률·연구 주제·대타를 정한다.
- **근무** (교대마다 8분): 사람들이 맵 위를 걸어 다니며 일한다. 교대마다 무전이 4~6번 온다.
  무전이 오면 멈추고, 선택지마다 성공 확률과 이유가 보인다.
- 낮은 **수습하고 준비한다** (돈과 시간): 트럭 출하, 원료, 주문, 지난밤 흔적 조사, 설비 점검.
- 밤은 **버틴다** (생존): 역압, '한 명 더', 정전, 이름을 부르는 소리, 박 씨의 무전.

## 사람 (18명)
| 조직 | 인원 | 근무 |
| --- | --- | --- |
| 1·2·3조 (반장 1 + 조원 4) | 15 | 3조 2교대: 주간 2일 → 야간 2일 → 휴무 2일 |
| 연구원·정비원·관리 사원 | 3 | 낮에만 |
| 박 씨 (용역 경비) | - | 통제할 수 없다 |

**대타**: 사람이 모자라면 퇴근하는 사람을 붙잡거나(바로, 지쳐 있음), 쉬는 사람을 부른다(약 1시간 뒤 정문 통과).
둘 다 위반 기록 1건과 수당이 붙는다.

## 생산과 돈
원료 탱크 → 반응실 → 정제실 → 창고 → 출하장 트럭(10시·16시, 드럼당 65). 원료는 드럼당 20, 월급·유지비는 교대 끝에 나간다.
창고에 사람이 없으면 정제실 출구(4드럼)가 막힌다. 7일마다 주간 결산.

## 조작
| 입력 | 동작 |
| --- | --- |
| 직원(명단이나 맵) 클릭 → 방 클릭 | 그 방으로 보낸다. 불 꺼진 방이면 가서 켠다 |
| 쉬는 직원 클릭 | 호출 |
| 방 위에 마우스 | 하는 일·필요 인원·지금 상태 |
| 스페이스 / 1·2·3 | 멈춤 / 배속 |

## v0.5에서 뺀 것
칸 건설, 복도 시스템, 전력, 탈환, 주 단위 근로시간 장부, 감사(→ v0.7에서 다시 설계).
이유는 기획서 20-5절: 화면에서 "무엇인가·어디서 오나·왜 신경 쓰나·어떻게 대응하나"가 보이지 않는 시스템은 뺐다.

## 파일
| 파일 | 역할 |
| --- | --- |
| `scripts/defs.gd` | 수치, 맵, 사람 명단, 근무표 (밸런스는 여기서만) |
| `scripts/sim.gd` | 규칙 전부: 근무·생산·무전·대타·연구·프롤로그 |
| `scripts/person.gd` | 직원 한 명 |
| `scripts/main.gd` | 화면과 흐름: 회의 → 근무 → 무전 → 보고서 |
| `scripts/world_view.gd` | 맵 그리기 (도형 임시 아트) |
| `scripts/sfx.gd` | 효과음 합성 (임시 소리) |
| `_sim/smoke.gd` | 규칙만으로 10일 자동 진행, 정책 3종 |
| `_sim/ui_autopilot.gd` | 실제 화면을 무작위로 눌러 끝까지 (오류 검사) |
| `_sim/shots.gd` | 가상 디스플레이에서 스크린샷 |
