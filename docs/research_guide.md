# 머신러닝 투자 연구 시스템 안내 (작업지시서 ②)

이 시스템은 **투자 연구와 의사결정을 돕는 도구**입니다. 실제 증권계좌 주문, 자동매매, 레버리지 기능은 없습니다.
모든 결과는 과거 데이터에서 나온 통계이며 미래 수익을 보장하지 않습니다.

## 1. 구성

| 엔진 | 위치 | 하는 일 |
|---|---|---|
| A. 데이터 조회 | `marketlab.api.MarketData`, `research/dataset.py` | 필요한 기간·컬럼만 DuckDB 로 읽음 (float32) |
| B. 특징 생성 | `research/features.py` | 가격·거래량·변동성·상대성과·기술적 지표·시장 환경 62개 특징 + 라벨 → `data/features/market=XX/year=YYYY` |
| C. 머신러닝 | `research/models.py`, `experiments.py` | 기준 모델·선형·LightGBM, 고정 분할 + walk-forward |
| D. 전략 탐색 | `research/strategies.py` | 규칙 전략 8개 + ML 전략 6개, 예산 내 파라미터 비교 |
| E. 백테스트 | `research/backtest.py`, `portfolio.py` | t+1 시가 체결, 비용·세금·거래대금 한도·기업행위·상장폐지 |
| F. 투자 분석 | `research/analysis.py`, `regime.py`, `monitor.py` | 시장 국면, 종목 분석, 후보 순위, 모니터링, 한국어 설명 |
| G. 과거 시장 게임 | `research/game.py` | 과거 날짜로 돌아가 투자, AI 와 대결 |

연구 결과는 `data/metadata/research.duckdb` 에 저장됩니다(실험, fold 결과, 예측, 백테스트, 모델 등록, 게임, 탐색 기록, 최종검증 접근 기록).

## 2. 시점 규칙 (미래정보 누출 방지)

```
t일 장 마감 ──► 특징 관측·예측 생성 (KR 18:30 KST / US 20:00 ET 까지 확정된 정보)
t+1일 시가  ──► 매수 체결 가정 (시가가 없으면 진입 불가 → 라벨 없음)
t+k일 종가  ──► 청산·수익률 계산   y_ret_k = I(t+k) / (I(t) × open(t+1)/ref(t+1)) − 1
```

- `I` 는 기업행위(분할·증자 기준가 조정)와 미국 배당을 반영한 누적 수익률 지수입니다. 과거에서 앞으로만 누적하므로 미래 기업행위가 과거 특징에 섞이지 않습니다.
- t 이전에 거래가 끝난 종목(상장폐지)은 마지막 종가까지의 수익률을 쓰고 `y_trunc_k=1` 로 표시합니다. 데이터 끝(최근)이라 미래가 아직 없는 행은 라벨을 비웁니다.
- 시장지표는 `available_at ≤ 의사결정 시각` 인 값만 씁니다. 한국 t일 특징에는 미국 t-1일 값까지, 미국 t일 특징에는 한국 t일 값까지 들어갑니다. 서머타임에 따른 시차 변화도 반영됩니다.
- 횡단면 순위 특징은 같은 날 투자 가능 종목 안에서만 계산합니다.
- **자동 누출 검사** (`tests/test_research_leakage.py`): 특정 날짜 이후 원천 데이터를 지운 상태로 다시 계산한 특징이, 저장된 특징의 그날 값과 62개 모두 같은지 확인합니다.

## 3. 학습·검증

- 기본 구간: 학습 ~2020 / 모델 선택 2021~2023 / **최종 독립 검증 2024~** (`config/settings.yaml` 의 `research.splits`).
- 경계마다 라벨 기간만큼 학습 행을 제거합니다(purge). 예를 들어 20일 라벨이면 경계 직전 21거래일 신호는 학습에서 빠집니다.
- 전처리(결측 대체·표준화)는 학습 데이터로만 적합합니다(sklearn Pipeline). LightGBM 조기 종료는 학습 구간 마지막 15% 날짜로만 판단하므로, 검증 구간은 순수하게 평가에만 쓰입니다.
- 확률 보정: 검증 구간 앞 절반으로 등위회귀 보정을 하고 뒤 절반으로 평가합니다.
- **Walk-forward**: 매년 그 해 이전 데이터로만 다시 학습한 뒤 그 해를 예측합니다. 확장형 창(처음부터)과 고정 길이 창(최근 8년)을 비교합니다. 예측은 `predictions` 테이블에 `model_trained_until` 과 함께 저장되며, 백테스트와 게임의 AI 는 이 예측만 씁니다.
- **최종 검증 통제**: 최종 검증 구간 평가는 `final_test()` 와 연구 전체 실행의 마지막 단계에서 한 번만 합니다. 모든 접근이 `test_access_log` 에 남고, 같은 실험을 다시 평가하면 '독립성 훼손' 경고가 붙습니다.
- **실험 기록**: 실험 ID, 시각, 데이터 버전(연도별 행 수), 기간(purge 반영), 특징 목록, 대상, 알고리즘·하이퍼파라미터, 시드, 학습 시간, 최대 메모리, 성능, 모델 파일, 코드 버전(git)을 모두 저장합니다.
- 전략 탐색은 선택 구간에서만 비교하고, 시도한 조합 수와 결과를 `strategy_search_log` 에 모두 남깁니다.

## 4. 예측 과제

| 과제 | 라벨 | 모델 | 주요 지표 |
|---|---|---|---|
| 향후 수익률 | `y_ret_{5,20,60}` | 0 예측, 과거평균, 모멘텀, 반전, 선형, Ridge, LightGBM | MAE, RMSE, IC, Rank IC |
| 상승 확률 | `y_up_k` | 항상 상승(기본비율), 모멘텀, 로지스틱, LightGBM + 보정 | AUC, Brier, 보정표, 상위 20% 실현수익 |
| 상대 순위 | `y_rank_k` (같은 날 백분위) | 모멘텀, 반전, Ridge, LightGBM | Rank IC, t값, 상위-하위 10% 수익 차이 |
| 위험 | `y_vol_k` (향후 실현 변동성) | 과거 변동성, Ridge, LightGBM | RMSE |
| 시장 국면 | 군집(GMM, 학습 구간 적합) + 규칙 이름 | – | 국면별 이후 수익률(서술 통계) |

## 5. 거래비용 가정 (출처와 한계)

| 항목 | 한국 | 미국 |
|---|---|---|
| 수수료 | 0.015% 양방향 (온라인 증권사 일반 수준, 가정) | 0% (주요 온라인 브로커) |
| 슬리피지·호가 차이 | 0.10% | 0.05% |
| 매도세 | 증권거래세+농특세 시점별 표: ~2019.6 0.30%, 2019.6 0.25%, 2021 0.23%, 2023 0.20%, 2024 0.18%, 2025 0.15%, 2026 0.20% (**공시 확인 필요한 가정**, 코스피 기준 단순화) | 없음 (SEC fee 무시) |
| 환전 | – | 원화 기준 비교 시 0.25% (설정만, 기본 계산은 달러 기준) |

과거 비용을 정확히 알 수 없으므로 최종 검증에서는 비용 0배·1배·2배 세 가지 시나리오를 함께 보고합니다.

## 6. 백테스트 처리

- 체결: 신호 다음 거래일 **시가(당시 실제 가격)** ± 슬리피지, 정수 주, 현금 범위 안에서만(무차입·공매도 없음).
- 기본 제약: 단일 종목 최대 10%, 주문 ≤ 거래대금의 5%. 화면에서 바꿀 수 있습니다.
- 기업행위: 한국은 기준가 조정일에 보유 수량 ÷ 조정계수(분할·병합은 정확하고, 유·무상증자는 가치를 보존하는 근사). 미국은 분할 비율만큼 수량을 조정하고 배당은 현금으로 입금합니다.
- **한국 배당 미반영**: 원천(marcap)에 배당이 없어 한국 성과는 연 1~2% 정도 과소평가될 수 있습니다.
- 상장폐지: 마지막 거래 이후 시세가 없으면 `last_close`(마지막 종가로 청산)로 처리합니다. `conservative` 는 합병·완전자회사화 같은 보상 근거가 없으면 0원으로 처리하며, 최종 검증에서 두 결과를 함께 보고합니다.
- 벤치마크: KOSPI·KOSDAQ(배당 미포함 가격지수), S&P 500·NASDAQ(가격지수), 투자 가능 종목 동일가중(비용 제외). 통화는 각 시장 현지 통화 기준입니다.
- 통계적 불확실성: 20거래일 블록 부트스트랩(1,000회)으로 CAGR·샤프의 90% 구간을 구합니다.

## 7. 사용 방법

```bash
marketlab research features --market KR            # 특징 생성 (변경된 연도만)
marketlab research train --market KR --task rank --horizon 20
marketlab research walkforward --market KR --task rank --horizon 20 --window expanding
marketlab research run-all --market KR             # 전체 연구 (재개 가능), 끝나면 reports/research_report_KR.md
marketlab research analyze --market KR             # 현재 시장 요약
marketlab research rank --market KR --horizon 20   # 후보 순위
marketlab research monitor --market KR             # 최신 예측 저장 + 성과 약화·분포 변화 점검
marketlab research models                          # 모델 목록
marketlab research promote --model-id <ID>         # 사용자 승인 (자동 교체 없음)
marketlab dashboard                                # 통합 화면 (7개 메뉴)
```

화면 메뉴: 1 데이터 현황 · 2 시장 분석 · 3 개별 종목 분석(후보 순위 포함) · 4 머신러닝 연구소 · 5 전략 백테스트 · 6 과거 시장 게임 · 7 시스템 관리

## 8. 자원 관리 (M1 8GB)

- 학습 스레드 2개, DuckDB 메모리 2GB.
- 학습 전 예상 메모리를 계산하고, 3GB 목표를 넘으면 실행을 거부하며 허용 행 수를 알려줍니다.
- 학습 중 프로세스 메모리가 4GB 를 넘거나 시스템 가용 메모리가 1GB 미만이면 중단합니다. 완료된 fold 는 저장되어 이어서 실행할 수 있습니다.
- 실측(개발 서버, 한국 전체): 특징 생성은 연도당 약 20~30초·약 2.1GB, LightGBM 학습(110만 행)은 약 45초·약 1.5GB.
- 메모리가 부족할 때는 다음 순서로 줄입니다: 특징 줄이기 → 표본 간격 늘리기(`sampling_every_n_days`) → 시장·기간 나누기 → 고용량 RAM 환경. **외장 SSD 는 저장공간 문제만 해결하고 RAM 부족은 해결하지 못합니다.**
- 저장공간: 학습 전 프로젝트 전체 예산(수집+연구 합산 30GB)과 내장 SSD 최소 여유 20GB 를 확인합니다(`DiskGuard`).

## 9. 한계

- 미국: 무료 원천에는 상장폐지 종목이 거의 없어 생존편향이 큽니다. 미국 결과는 실제보다 좋게 나올 수 있습니다.
- 업종: 시점별 업종 분류 이력이 없어 업종 특징·업종 비중 제한은 구현하지 않았습니다(현재 분류를 과거에 쓰면 미래정보가 됩니다).
- 재무: 한국은 OpenDART 키가 없어 재무 특징이 없습니다. 미국 SEC 재무(`financial_facts`, 제출일+1일부터 사용)는 수집됐지만, 증권 ID 와 CIK 의 시점별 연결이 불완전해 현재 모델에는 넣지 않았습니다(가격·거래량 모델만으로 완결).
- MACD 는 지수이동평균 대신 단순이동평균으로, ADX 는 추세효율비로 대체했습니다.
- FRED 지표는 수정본이며 빈티지(당시 발표치)가 아닙니다. 금리·시장지표는 수정이 거의 없습니다.
